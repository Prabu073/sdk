# Sample Applications

| # | Sample | Difficulty | Language | Demonstrates | Ready-made download |
|---|---|---|---|---|---|

## Two ways to use a sample

### Try it immediately

Download a sample ZIP, deploy it as an On-Prem Extension, and add its action to a Flow. No local Java setup is required for this path. Follow the [ZIP-to-Flow guide](../README.md#deploy-to-zoho-flow), then use the sample's README for its inputs and expected output.

### Modify it

Open the language implementation, edit its source, and run the provided build script. Each language README documents its SDK version, expected JSON, build output, and packaging rules.
