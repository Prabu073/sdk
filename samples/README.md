# Sample Applications

Samples are ordered from the simplest connector contract to more advanced Zoho Flow capabilities. Only implemented language directories are shown.

| # | Sample | Difficulty | Language | Demonstrates | Ready-made download |
|---|---|---|---|---|---|
| 01 | [Hello Static](01-hello-static/README.md) | Beginner | Java | Static action input and output | [hello-static.zip](01-hello-static/java/hello-static.zip) |

The machine-readable catalog is available in [`catalog.json`](catalog.json).

## Two ways to use a sample

### Try it immediately

Download the sample ZIP and upload it through the Zoho Flow custom-class/library interface. No local Java setup is required for this path.

### Modify it

Open the language implementation, edit its source, and run the provided build script. Each language README documents its SDK version, expected JSON, build output, and packaging rules.
